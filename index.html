NOTAS / METODOLOGIA

UM RETRATO
DE UMA ERA.

Dados do ranking público Achikochi Data, que informa atualização diária. O site lê um arquivo JSON atualizado por uma rotina agendada no GitHub Actions, sem chave da API do YouTube. As miniaturas e links diretos vêm dos identificadores de vídeo publicados na página de detalhes da fonte. O navegador sozinho não consegue garantir a leitura direta de sites de terceiros devido a restrições de CORS. Sem publicação e automação, o site exibe o retrato histórico e indica isso claramente. A fonte usa sua própria seleção de vídeos; não representa todo o YouTube.
